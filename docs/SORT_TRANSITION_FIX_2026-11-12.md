# 单节点排序跳动修复与验证

> 后续修正：用户在首轮修复后确认菜单缺少切换反馈。本轮改为快捷菜单与分组整体切换网格，恢复原地淡入。下方首轮结果保留为历史记录，最终方案与新验证见文末。

## 问题与边界

用户在 V2.8.7 Stable 的无痕窗口发现：只有一个节点时，点击总流量、峰值，卡片先出现在中间，随后回到左侧。

已观察用户的无痕候选页面能够展示首页和三网。原生窗口持续检测到人工输入，自动点击未完成，因此不把生产页面的动态复现或完整权限验收记为通过。复现和修复后验证使用回环地址的合成节点，不使用生产凭据，不更改站点权限、后端配置或安装版本。

## 原因与实现

旧组件 key 包含所有快捷按钮的状态。总流量、上行、下行、峰值只改变排序，却也触发整张卡片离场和重建。离场元素在动画结束前仍占据第一格，新元素进入第二格，旧元素移除后新元素回到第一格。

在本地 1280px 宽度复现：动画期间同时存在两张代表同一节点的卡片，旧卡片 x=16，新卡片 x≈330；动画结束后只剩一张，x=16。

修复使四种纯排序与默认顺序使用同一节点身份，保留 Vue TransitionGroup 的换位动画。收藏、离线、高负载、即将到期等成员筛选，以及分组、首次进场，保留各自原有过渡。没有修改网格尺寸、动画参数、数据传输、鉴权和后端接口。与上游的这一处排序身份差异已记录到 fidelity-audit.md。

- `bun run lint`、`bun run typecheck` 通过；另用便携 Node 22 直接执行 vue-tsc，通过。
- `bun run test`：70 个文件、822 项测试通过。新增测试覆盖四种排序身份不变、成员筛选和不同来源节点身份区分；接线契约同时检查 HomeView 调用该函数。
- `bun run build`、`bun run validate:dist` 通过；产物为 index.html 加 26 个 assets。既有大分包提示仍存在。
- `bun run verify:security` 与 `git diff --check` 通过。
- 本地浏览器在 1280px 反复切换总流量、峰值和取消排序，连续 DOM 采样均只有一张卡片、x=16，无 enter/leave 类。
- 320、375、768px 重复切换，采样均只有一张卡片、x=16，无横向溢出；已恢复浏览器默认视口。
- 本地浏览器控制台未捕获 error。截图与前后采样保存在被忽略的 outputs 目录，不提交到公开仓库。

本轮没有重新完成真实 Cloudflare 四种权限组合验收，也没有安装线上修复版。代码和文档留在本地，未提交、未推送、未创建 Release。用户后续提交推送后，需要等待新 dist 构建并改用新的固定提交地址；旧候选地址不会自动包含这次修复。

## 后续修正：恢复快捷菜单的可见过渡

用户安装首轮修复后报告：总流量/峰值没有切换反馈，希望能像分组切换一样看出菜单变化。已在用户标记的线上标签复核：总流量→峰值连续采样的卡片 opacity 始终为 1；VMiss→全部节点则有 enter-active，opacity 从 0 递增至 1。线上测试后已恢复原 VMiss 分组和总流量选择，没有改后端设置。

最终方案把分组与快捷菜单选择共同作为卡片网格标识，节点仍使用含来源的 server.key。切换时旧网格直接移除、新网格按既有 appear 动画原地淡入，与原分组切换的实际机制一致；不依靠新旧卡片在同一网格里共存来播放动画。总流量、峰值互切及取消选择都有反馈。实时指标、搜索和同一菜单内的自动排序不改变网格标识，不反复重播。禁用动画、系统减少动态效果和大节点集合仍遵守原规则。没有增加依赖或改变 API 请求逻辑。

最终验证：

- lint、Bun 下 typecheck、Node 22 直接执行 vue-tsc、70 文件 822 项测试、生产 build、validate:dist、安全模式扫描、diff 空白检查均通过。
- 本地合成单节点，使用与线上一致的舒适密度，桌面 1443px：依次总流量→峰值→取消峰值→总流量→取消总流量，各次均捕获 enter-active；全程最多一张卡片，布局 offsetLeft 一直为 93。捕获透明度低于 1，稳定后为 1。
- 320、375、768px：均捕获进场动画、最多一张卡片，布局 offsetLeft 为 16，无横向溢出；浏览器视口已恢复默认。
- 浏览器没有捕获 error；本地测试临时保存的卡片密度已通过“使用后端配置”清除，本地覆盖恢复为 0 项，临时标签已关闭。
- 截图与连续 DOM 采样仅存 outputs/menu-transition-restored.png、outputs/menu-transition-evidence.json，均被 Git 忽略；静态截图仅展示最终布局，透明度与节点数以采样记录为证。
