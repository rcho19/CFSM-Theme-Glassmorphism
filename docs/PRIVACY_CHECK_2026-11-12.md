## 隐私提醒与限制

- 若希望隐藏邮箱，到 GitHub 个人 Settings → Emails 获取 GitHub 提供的 noreply 地址，再在本仓库设置 `git config --local user.email "你的 GitHub noreply 地址"`。仅更改设置不影响既有提交。旧提交及构建提交可能继续引用旧元数据；重写公开历史需要单独明确授权，且无法保证清除第三方缓存。
- 仓库现有工作流仍支持 v 开头标签触发发布任务。候选阶段只使用 main 与 dist，不推送 v 标签，不创建稳定 Release。
- 本轮没有访问仓库 Secrets 的值、读取 Actions 全部日志/归档附件、检查所有隐藏远端引用或 GitHub 缓存；二进制截图没有逐像素审查。文本扫描无法穷尽自定义或编码后的秘密。
- 自定义背景、公告图片会接触运营者指定的资源来源；Turnstile 使用 Cloudflare 官方域名。同源恶意脚本仍可能读取 localStorage，前端不能代替后端鉴权。
- 本轮只刷新隐私、依赖公告和构建核验，未重新运行整个应用功能测试套件。上轮功能结果见 IMPLEMENTATION_RESULTS.md；生产权限、Turnstile 和真实探针数据需另行验收。
