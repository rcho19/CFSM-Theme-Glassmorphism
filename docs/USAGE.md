# 使用和公开发布说明

当前为候选版 1.3.0-rc.1，不是原移植版 v1.2.0 的官方更新。保留原作者 MIT 许可和署名。版本说明和固定安装地址见 [v1.3.0-rc.1](releases/v1.3.0-rc.1.md)，只有完成真实站点验收后才适合标记稳定版。

## 同源安装

1. 将源码上传到你自己的 GitHub 仓库，默认分支使用 main。
2. 在 Actions 中允许工作流写入仓库内容。Build 会先检查、测试、构建和审计，通过后追加提交到 dist 分支。
3. 在 CFSM 管理端的自定义主题 URL 填写 `https://github.com/<你的用户名>/<你的主题仓库>/tree/<dist的完整40位提交SHA>`。
4. 安装后验证首页、节点详情、三网、后台入口和主题配置保存；保留原主题引用以便回滚。

dist 是构建产物分支，不是本地 dist 文件夹。生产安装优先固定完整提交 SHA，不依赖滚动分支缓存刷新。不要把原作者的仓库地址当成你当前修改的安装地址。

### 备份、预览和安装的实际入口

这里的“备份”是把当前主题地址和配置复制到电脑上的私人文件，不需要先备份或重建 Worker、D1、Agent。`/api/config` 是接口地址，不是菜单；通常无需打开它。

1. 在现有 CFSM 域名下打开 `/admin#/admin` 并登录，保留这个管理端标签页。管理端与主题首页的“主题设置”不是同一个页面。
2. 进入管理端“主题商店”，复制当前“自定义主题 URL”输入框中的原主题地址；若原来使用内置主题，记录“内置主题”。如果输入框没有显示旧地址，先确认现用主题及其固定版本地址再切换。
3. 进入管理端“设置”，找到“外观 2”中的“主题自定义配置 JSON”，复制整个文本框内容到仓库之外的私人文件；不要改动或点击保存。它对应 `theme_options`。仅复制此配置即可，不要导出 Cookie、JWT、HAR 或包含账号、通知 Token 的完整后台配置。
4. 同一“设置”页面的“显示选项”中，记录“公开访问”和“显示三网详情”的原值。记录全局 Turnstile 的原开关状态；它与“仅登录验证”的开关不同。首次试用保持现有访问权限不变。
5. 回到“主题商店 → 自定义主题 URL”，粘贴自己仓库 dist 分支的固定提交地址。若有“预览”，可先预览；预览用于初步看布局，不能代替正式同源安装后的权限和 WS 验收。需要启用时点击“应用自定义”，再在另一标签页打开站点首页。这会更换访客看到的主题，应安排合适的测试时段。
6. 若“显示三网详情”原本关闭，需要在管理端“设置 → 显示选项”开启并保存。候选主题首页进入“主题设置 → 三网”，开启“启用新版三网”，首次点击“保存到此浏览器”；先不点击“保存到 CFSM 后端”。本地保存只影响当前浏览器，后台的三网详情开关则作用于站点。

“外观 2”仅在管理端当前页面与所选 API 站点同源（或本地开发）时显示；找不到时先确认没有在多站点选择器中选中另一个站点，再核对 Workers 版本。上述名称对照 CFSM 管理端源码，不是第三方主题页面中的菜单。

回滚时在保留的管理端“主题商店”重新填入原主题 URL 并点击“应用自定义”；原来是内置主题则点击“使用内置主题”。若改过后端主题配置，把备份 JSON 粘回“设置 → 外观 2 → 主题自定义配置 JSON”并保存；同时恢复实际改动过的站点开关。后台数据不需要恢复时不要额外覆盖。候选主题中“使用后端配置”只清除此浏览器的主题覆盖，不会恢复旧后端配置，也不能撤销主题安装。

管理端源码参考：[设置页面](https://github.com/rcho19/CF-Server-Monitor/blob/main/src/frontend/views/admin/components/SettingsPanel.vue)、[主题商店](https://github.com/rcho19/CF-Server-Monitor/blob/main/src/frontend/views/admin/components/ThemeStorePanel.vue)。不同版本的位置可能变化。

## 新版三网

在 CFSM 后台开启三网详情，然后在主题设置中开启“启用新版三网”。默认 ct/cu/cm，最多三条；全局设置按数据来源保存，单节点覆盖包含来源和节点 ID。选择器可移除失效绑定或恢复默认。未配置、无采样、超时和 0 是不同状态。

小曲线和色块都展示列表首次返回的两小时采样窗口快照，显示获取时间；不是持续滚动的一小时完整探测统计。旧快照会标记，页面恢复可见时按官方规则补取列表。不会每五分钟轮询，也不会逐台请求历史。线路名称或数值按钮可进入详情；图上可用鼠标、触屏或左右方向键查看时间桶。

从详情/设置主动返回缓存首页时也会补一次列表快照；从负载“实时”切回历史档位时补一次所选窗口。历史仍是服务端返回时的快照，可能受服务端缓存和分桶影响，不承诺最后一个点等于当前时间。首页的两小时平均丢包率与详情所选范围（默认十分钟）的平均丢包率可以不同；应先核对统计范围，不能据此认定数据错误。

详情默认 10 分钟，负载与延迟共用历史范围；用户切换范围才查询对应的 `/api/history/all`。WS 断开后指数退避最多十次；不进行定时 REST 回退。后台关闭三网详情或没有窗口时不绘制历史小图。

### 负载实时与 Agent 上报方式

Agent WSS 是可选能力，不是使用本主题或发布稳定版的前提。关闭 WSS、节点仅使用 HTTP POST 时，数据按节点的实际上报周期到达，不能期待每几秒更新。实时负载图会先显示最近十分钟的已有历史，再接续收到的真实样本；秒级与毫秒级历史时间戳均受支持。相邻样本超过一分钟保留缺口，孤立样本显示为圆点，连续样本绘为折线，不跨缺口插值，也不额外轮询凑点。若需要高频曲线，再单独评估开启 Agent WSS 和节点自动连接模式。

本地保存只影响该浏览器。保存到后端需要在同源 CFSM 官方管理端登录，将向 `/api/theme_options` 提交完整快照；多人同时编辑仍有最后写入覆盖风险。“导出二级密码”只是前端确认文本，不是安全边界，不应填写真实密码。

如需公开页面仅供查看，在管理员登录状态下打开“主题设置 → 高级工具与隐私”，开启“未登录时隐藏主题设置”，点击“保存到 CFSM 后端”。未登录访客将看不到设置按钮，直接打开 `#/settings` 也会返回首页；刷新、明暗切换、筛选和详情查看仍可用。“隐藏后台入口”是另一个独立开关。只保存到此浏览器不会限制其他访客；新功能需安装包含此修复的候选构建后才可使用。

## 独立 Pages 部署

在仓库 Settings → Pages 选择 dist 分支、根目录。按需在 Actions Secrets 配置下列公开运行参数，全部可留空用于同源安装：

| 名称 | 内容 |
|---|---|
| API_BASE | HTTP(S) 纯 origin，多个来源逗号分隔 |
| TITLE | 站点默认标题 |
| BACKGROUND_IMAGE | 默认背景 URL；主题后台明确配置优先 |
| CSP_API | 额外允许的 API origin，逗号分隔 |
| CSP_STATIC | 图片和媒体允许来源，逗号分隔；外部背景来源也需列入 |

这些值会进入浏览器可读的 HTML，使用 Secrets 只是避免写死到源码，不能隐藏站点地址。严禁填入 API_SECRET、JWT、Cookie、密码或含凭据 URL。Worker 的 `CORS_ALLOWED_ORIGINS` 需允许 Pages 的纯 origin。

本版多源默认匿名：不把同源 JWT 发给其他来源，不在 WS URL 放主站凭据。跨源私有站点和独立跨源 Turnstile 授权尚未提供，不应宣称受支持；有此需求请同源安装，或另行实现逐 origin 的显式授权流程。不能为“让它能连上”而恢复全站共享 JWT。

## 开发与验证

需要 Node 20.19+ 或 22.12+，Bun 1.4.4。源码采用 Vue 3、TypeScript、Vite、ECharts 和 reka-ui。

```sh
bun install --frozen-lockfile
bun run dev
bun run lint
bun run typecheck
bun run test
bun run build
bun run validate:dist
bun audit
```

开发服务器没有内置生产探针，也不会自动使用你电脑上的凭据。Windows 若 Bun 下 SFC 检查异常，使用符合版本要求的 Node 执行 `node node_modules/vue-tsc/bin/vue-tsc.js --noEmit -p tsconfig.json`，不能跳过模板错误。

本地构建包根目录必须只有 index.html 与 assets/。正式构建使用 Actions；不要提交 node_modules、dist、.env、outputs 或本机审查日志。

离线界面验收可以在构建后执行 `bun run preview:fixture`，打开 `http://127.0.0.1:4178`。该服务仅监听回环地址，使用明确命名的合成节点并拒绝配置写入；不连接真实 Worker，不会进入生产包。使用完后在终端按 Ctrl+C 结束。

## 发布前检查和回滚

- 真实验证公开/私有 × Turnstile 开/关四种同源组合，检查首页、WS、详情和保存；本地模拟不能代替真实 Cloudflare 验收。
- 验证 320/375/768/1440 宽度、明暗、所有卡片密度、键盘和触屏交互。
- 检查浏览器网络请求无未知来源；源码、依赖和构建产物扫描均通过。
- 备份旧主题引用及 theme_options；使用独立候选提交，不覆盖已有稳定标签。
- 出问题时切回旧主题引用，并按需恢复旧配置；旧版会忽略新增三网键。

## 安全报告

请使用你自己仓库的私密漏洞报告渠道。不要在公开 Issue 粘贴真实 Token、Cookie、API_SECRET、服务器 IP 清单或订阅链接。已知限制见 SECURITY.md，实施边界见 IMPLEMENTATION_SPEC.md。
