# 访客主题设置入口控制

## 目标、范围和回滚

增加独立的“未登录时隐藏主题设置”，不合并既有后台入口开关。范围包含 schema、完整保存快照、设置表单、三页共用 Header、直接路由和授权变更响应。默认 false 保持旧行为；不改服务端、刷新按钮或节点读取权限，不部署、不写生产配置。

先实现后端策略解析与渲染限制，再做登录/访客及本地覆盖行为测试、合成浏览器验证，最后跑质量门。验收应覆盖：开启后访客入口隐藏且直接访问回首页；管理员可进入；旧配置行为不变；本地覆盖不能解除策略；冷启动不闪现表单。回滚可由管理员登录后关闭并保存后端开关，或回退代码重建；后者不再提供新入口限制，服务端管理员鉴权不受影响。

## 实现

新键 `hideThemeSettingsWhenLoggedOut` 默认 false，已知设置数从 51 变为 52。只有后端主站配置能控制该策略：本地预览和保存不改变访客访问范围。管理员授权由 CFSM `authorization` 确认；后端保存仍要求原有 JWT 校验，不把“显示设置页”当成写入授权。该功能不保证隐藏公共 API 返回的配置，不能用于保密。

## 验证

Node 22.23.4 / Bun 1.4.4 下 lint、Bun typecheck、Node 直接 Vue SFC typecheck、完整测试（70 文件 / 828 项，单工作进程）、生产构建、dist 校验、安全扫描和差异空白检查通过；没有改依赖或构建配置。保留既有大资源分包提示。

使用本地 mock 的 `CFSM_FIXTURE_SETTINGS_POLICY=guest` / `admin` 验证相同后端开关下两种授权状态：

- 访客直接进入 `#/settings`，最终地址为 `#/`，设置链接和表单数量均为 0，刷新按钮仍为 1；进入详情后设置链接也为 0。
- 管理员模拟授权下，设置链接为 1，能够打开 `#/settings`，完整表单及新开关均为 1。此 mock 没有模拟真实 JWT 登录或配置写入，不能据此宣称生产保存通过。
- 未指定新策略的默认匿名配置仍可进入设置页，表单和设置链接均为 1；旧配置行为保留。
- 浏览器未捕获 error；没有保存本地覆盖，没有访问生产管理页。截图仅保留在被忽略的 outputs/settings-guest-hidden.png；测试标签及服务已关闭。

单测另覆盖访问策略变更：后端禁止不能被本地 false 覆盖或预览解除；主站授权由 true 变为 false 时访问状态立即变为 blocked；无已确认配置且配置失败时不暴露表单；新键严格解析并包含在完整保存快照中。
