# 候选版测试反馈核对

## 范围与计划

用户提供日常站点手工测试记录。本文件只摘要相关结果，不复制原始私人文档或节点资料。目标是核对两项明确异常（切换节点按钮的等待光标、首页与详情丢包率不同），并处理前后台恢复一节提到的旧快照。阶段：定位语义及生命周期 → 定向回归 → 本地修复 → 合成浏览器与完整质量门。不更改 Worker/Agent、生产设置，不推送或发布新版本。

验收：不可用导航不显示等待光标；返回首页补一次列表快照且不轮询；从实时返回原历史范围补一次共享历史请求；真实丢包统计不改写，清楚标识详情统计范围。风险是用户主动返回页面/历史时增加一次读取，必须保持冷启动预算及在途去重。回滚仅还原本轮样式、生命周期及范围选择改动并重建，无须修改数据库。

## 用户反馈与证据边界

- 用户报告四种公开访问/全局 Turnstile 组合、管理员查看保存及新无痕读取、访客设置路由限制通过，未出现白屏或持续错误。这是用户手工验收，不等同于本轮逐请求安全审计。
- 首次验证约 67 分钟后再次触发验证并成功恢复，与服务端验证凭据有效期约一小时一致；26 分钟时没有再次验证不算异常。后台停留期间短暂显示离线还受五分钟在线阈值影响，不能单凭此判定 Agent 真离线。
- 用户报告可切回内置主题，再切回候选主题，首页/详情/历史和管理端正常，主题 JSON 在切换时保留。该记录验证主题安装回滚，没有实际覆盖并恢复旧 JSON，因此配置恢复演练仍不能记为通过。

## 核对结论与处理

1. 共用 `.icon-button:disabled` 使用 `cursor:wait`，单节点下不可用的上一台/下一台按钮也显示等待光标。本地已将普通禁用态改为禁止光标，仅真正刷新中的按钮保留等待态。
2. 首页三网为两小时列表窗口，详情为所选历史窗口（默认十分钟）的采样平均丢包率。不同时间范围内分别出现非零与零可以同时成立；合成数据回归验证该事实，不改变统计值。用户补充当时未留意范围，随后主动切换范围已观察到丢包统计变化，支持范围差异解释。目前未确认计算 Bug，补充 tooltip 的采样和范围说明；没有取得异常当时相同范围原始数据，不宣称已做逐点等值核验。CFSM 参考源码的长时历史使用每桶抽取整行、首页窗口取样顺序与之不同，统计值也不保证跨接口完全相同。
3. 首页 KeepAlive 恢复时旧实现只重启连接而不补列表；从实时切回未变化的历史范围旧实现不请求历史，都能保留旧快照。本地已只在这两种用户导航动作补一次请求，不增加任何定时 REST、逐卡历史或重复配置请求。CFSM 参考实现对六小时历史还有五分钟服务端缓存，重新请求不保证最后采样立刻等于当前时间，不用绕缓存参数或伪造末点。首页共享在途刷新，激活版本号防止离开后的旧回调重新打开全量连接。
