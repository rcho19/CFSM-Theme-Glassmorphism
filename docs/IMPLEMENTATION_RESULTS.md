## 浏览器验收

使用 `tests/browser/mock-server.mjs` 提供纯合成数据，仅监听回环地址；模拟服务不是 CFSM 服务端兼容证明，不处理真实账号或生产配置。

- 320/375/768/1440 像素：文档 scrollWidth 等于 clientWidth，三网行无溢出。发现并修复旧版 body/html 固定 320px 最小宽度与滚动条叠加造成的横向溢出。
- mini/compact/comfortable/large：逐一通过设置页切换并检查三网行宽度，无横向溢出。
- 浅色/深色、小曲线/色块、本地保存、三条线路选择上限、键盘历史查看、详情入口均有交互验证。
- 详情负载和延迟均默认选中 10 分钟；被观察的浏览会话中配置和列表各请求一次，首次详情历史请求一次。
- 最终观察未见浏览器控制台 error。截图为合成节点，不应作为真实节点运行截图。

物理触屏设备、所有浏览器版本和完整长时间压力测试尚未覆盖。指针事件已实现，但不把桌面 PointerEvent/键盘验证冒充物理触屏实测。

## 公开前仍需完成的事项

1. 在真实同源 CFSM 中验证公开/私有 × Turnstile 开/关四种组合，检查 Cookie、JWT、CSP、CORS、验证续期和配置保存。未通过前不能标记稳定版。
2. 跨来源私有和跨来源 Turnstile 授权目前不受支持，默认匿名；需要时另做逐来源的显式授权设计，禁止恢复共享 JWT。
3. 当前界面主要为中文，未实现完整 default_language 多语言文案，不能宣称所有语言兼容；这不影响接口字段解析，但属于平台能力差异。
4. theme_options 全量保存仍没有服务端修订号锁，多管理员并发写入存在覆盖风险。前端确认用“导出二级密码”不是秘密或权限控制。
5. 用户选择自己的公开仓库后，可配置 origin 并上传；Actions 的真实运行、dist 分支和 GitHub Pages 必须再核验。本轮没有修改任何 GitHub 外部状态。

没有已确认的凭据外传路径遗留在本轮修复范围内，但依赖审计、模式扫描和测试均不能证明绝对无漏洞。配置的第三方图片/背景、CFSM 后台自定义脚本以及浏览器扩展仍属于各自信任边界。
