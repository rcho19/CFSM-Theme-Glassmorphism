# 隐私与安全边界

本分支不新增遥测、广告、指纹、IP 地理查询、远程执行和运行时图标 CDN。系统指标由 CFSM API 提供，不向作者的服务转发。所有代码和构建流程供公开审查；不能保证绝对无漏洞。

## 网络来源

- `/api/config`、`/api/servers`、`/api/server`、`/api/history/all`、`/api/ws`：仅配置的 CFSM 来源。
- `/api/theme_options`：唯一主题写端点，只允许当前页面同源保存。
- `/flags/`、`/os-icons/`、`assets/`：图标和静态资源；不打包服务端秘密。
- Turnstile 启用时加载 `challenges.cloudflare.com` 官方脚本和验证框。
- 运营者自定义的背景、公告图片会访问配置的资源来源，应配合 CSP；不需要它们时保持关闭。
- 汇率使用缓存、内置参考值和手动覆盖，不再自动请求第三方汇率服务。CPU 排行和页脚是用户点击的外部链接。

JWT 和验证凭据保留 CFSM 的同源 localStorage/Cookie 约定，外源默认匿名，远端 401/403 不会清除主站会话。浏览器同源 XSS 或恶意自定义站点脚本仍可能读取 localStorage；主题不能代替后端鉴权、CORS、CSP 和账号安全。

这里的“外源匿名”指主题不主动附加主站凭据，HTTP 使用 credentials: omit，WS 不追加主站 JWT。原生 WebSocket 是否自动带目标站点 Cookie 由浏览器 Cookie 策略控制，不能把这一点表述成对浏览器所有 Cookie 的绝对隔离保证。

首个配置请求之前尚不知道 Turnstile 开关，允许复用该同源已存验证凭据；确认关闭后不再附带验证头。过期验证允许按 CFSM 流程重新获取配置，不以无限 reload 处理错误。

## 数据与权限

三网历史是采样快照，不把未配置和缺采样变成 0；实时消息只增量合并已知字段。不调用管理写接口，不实现主题内登录/管理后台。私有站点同源 401 清凭据并进入官方后台，非授权列表刷新不保留受限旧快照。

前端隐藏价格、导出二级密码、主题设置保存按钮禁用均不是服务端安全边界。theme_options 可被访客读取，不能放任何秘密。跨客户端并发保存缺少服务端版本锁，仍可能最后写入覆盖。

## 供应链与公开仓库

冻结 Bun 锁文件，已升级 Vite/Vitest 并限定修复版传递依赖。Bun 1.4.4 支持锁文件中的版本限定覆盖。`bun audit` 是已知公告检查，不等于人工审计全部依赖；发布前必须重新执行。

CI 对 dist 采用普通 push、父提交追加历史，不强推。CI 的仓库 Token 只用于当前仓库构建发布；它不进入前端。部署参数即使来自 GitHub Secrets，写进 HTML 后也是公开值。

本轮没有连接真实 Worker 或真实管理员会话。公开/私有及 Turnstile 的真实组合验收、所有目标浏览器和 Cloudflare 运行策略在发布前仍必须通过；未完成时只能标记开发候选版。

当前本地验证结果和未覆盖事项见 IMPLEMENTATION_RESULTS.md。依赖审计在 2026-11-11 未命中已知公告；发布时必须重新检查，不把该历史结果视为持续保证。
