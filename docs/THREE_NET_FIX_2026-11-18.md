# 首页三网入口、文字与间距修正

## 行为

- 三网名称、平均延迟和丢包按钮进入详情延迟区，刷新链接仍可恢复该区；普通卡片入口继续打开概览。
- 分区模式激活“延迟”，堆叠模式等待数据加载后滚动到延迟区域；不增加 API 请求或改变历史范围。
- 按用户确认的改进方案，名称与“丢包”两字使用主题中性色；常规延迟（≤160ms）使用中性色加粗，超过既有 160/200ms 阈值或不可达时才使用警示色。丢包数值沿用既有五级阈值，采用独立的文字色板。
- 新增 6px 状态圆点，与曲线保持原信号色；文字色板分别适配浅色、深色及色觉友好模式，不更改全局信号令牌。
- 名称与数值按内容宽度排列，各行共享列宽，数值到曲线固定间距 4px；长名称省略并保留完整提示。

## 上游依据

2026-11-18 读取 Komari 默认分支的 [NodeThreeNetPing.vue](https://github.com/sanrokamlan-prog/komari-theme-Glassmorphism/blob/main/src/components/NodeThreeNetPing.vue) 与 [HomeView.vue](https://github.com/sanrokamlan-prog/komari-theme-Glassmorphism/blob/main/src/views/HomeView.vue)：入口打开共享 Ping 弹窗，不按单运营商过滤。本项目遵循 `IMPLEMENTATION_SPEC.md` 复用详情页的要求；中性色标签、状态圆点及紧凑列布局参考上游；常规延迟中性色与独立文字色板为用户随后明确确认的视觉调整，详见 fidelity-audit.md。

## 本地验证

- lint、Bun typecheck、独立 Node 下 Vue SFC typecheck、832 项测试、build、validate:dist、git diff --check 均通过。
- Chrome 本地生产构建 + 合成数据：320 / 375 / 768 / 1440px，浅色与深色共 8 组均无横向溢出；名称及“丢包”文字与曲线的计算颜色不同，数值到曲线的间距均为 4px。
- 8 组均验证点击三网后显示延迟区、刷新后保持延迟区；另验证关闭分区标签时会滚动至延迟区域，受页面底部限制时停在最大滚动位置。
- 配色优化后重新通过全部质量检查；8 组浏览器复验确认常规延迟为中性色、字重 600，圆点与曲线同色，丢包文字色与曲线分离。另用合成的 180ms、240ms、100% 丢包验证浅/深色 × 标准/色觉友好 × 四种卡片密度共 16 组，实际警示色符合对应模式，不可达语义保留，320px 无横向溢出，每行高度保持 22px。
- 保留既有构建大分块提示；没有修改依赖、发布或部署。真实站点与完整设备矩阵未验证。
