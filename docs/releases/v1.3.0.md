# v1.3.0 正式版

本二次开发分支的 1.3.0 正式版，包含 rc.1 的全部功能及候选期间的修复，保留 MIT 许可和原作者署名。

## 新增与修复

- 新版三网按来源与节点选择最多三条线路，提供小曲线、色块与键盘/触屏历史点选择，默认关闭以兼容旧配置。
- 强化同源凭据边界及多来源名称归属；远端默认匿名，跨来源私有及独立 Turnstile 授权暂不支持。
- 遵守 CFSM 请求额度：配置按来源共享，详情默认十分钟，负载与延迟共用历史请求，不做定时 REST 轮询或逐卡历史请求。
- 修复稀疏实时采样不可见及秒/毫秒时间戳裁剪；真实缺口保留，不插值、不补零。
- 增加独立的“未登录时隐藏主题设置”，以保存到后端的配置决定访客入口与路由限制。
- 修复禁用节点导航的等待光标、返回首页及从实时返回历史时的旧快照；仅在主动导航时补一次读取。
- 跨历史范围加载时保留上一份成功数据和图表空间，加载完成才替换；旧数据仍标记原范围，失败如实提示。

## 丢包口径与验收

首页显示列表接口最近两小时有效时间桶的采样平均值（一位小数）；详情显示所选历史范围有效采样的平均值（两位小数）。不同范围和分桶取样可以产生不同结果，不能把它们当成同一份原始探测包统计，也不能为使数字相等而改写数据。

发布前已从真实浏览器成功响应独立复算：首页电信 20 个有效桶含两个 16%，均值为 1.6%；联通和移动均为 0%。十分钟详情当次 5 个有效采样的三条线路均为 0%，与页面 0.00% 一致；后续非零响应的电信 5 点为 0、33、16、0、16，均值 13%，与页面 13.00% 一致。该结论验证主题忠实展示接口采样，不代表所有原始网络探测包的加权丢包率。

四种公开访问/全局 Turnstile 组合、管理员保存与无痕读取、验证续期恢复、内置与候选主题切换已有用户手工验收。证据归属和本轮质量门见 [正式版验收](../RELEASE_READINESS_2026-11-13.md)。正式 ZIP 由标签 Actions 重新校验、构建及打包。

## 已知限制

- 仅 HTTP 上报仍受支持，数据按 Agent 上报周期到达；未启用 Agent WSS 的站点不保证秒级连续实时曲线。
- 长历史受后端分桶及缓存影响，主动刷新不保证末点立刻等于当前时间。
- 旧配置覆盖恢复演练、物理触屏及完整跨浏览器矩阵尚未完成；375px 部分总览长数值可省略。
- 实际部署中的第三方统计脚本来源未核实，主题源码及构建产物未包含该脚本。
- 后端完整配置保存无修订号锁，多管理员并发可能最后写入覆盖；安全扫描不构成绝对无漏洞保证。

## 安装与回滚

[固定安装 v1.3.0](https://github.com/rcho19/CFSM-Theme-Glassmorphism/tree/theme-v1.3.0)；也可下载 Release 附件 `CFSM-Glassmorphism-v1.3.0.zip`。安装地址使用产物标签 `theme-v1.3.0`，源码标签 `v1.3.0` 不能直接安装。稳定滚动分支 `theme-dist` 会在质量门通过后更新。

升级前在私人位置备份当前主题固定引用与 `theme_options`，保留已登录管理页。需要回滚时重新安装原主题，必要时恢复对应配置备份；[rc.1 固定安装地址](https://github.com/rcho19/CFSM-Theme-Glassmorphism/tree/theme-v1.3.0-rc.1) 保持不变。详见 [使用说明](../USAGE.md)。本次发布不自动替换日常站点主题或修改生产配置。
