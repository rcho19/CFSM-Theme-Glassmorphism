# v1.3.0-rc.1 候选版

这是 rcho19 二次开发分支的首个 1.3.0 发布候选，基于 CFSM Glassmorphism 移植版继续开发，保留 MIT 许可及原作者署名。本版用于测试与反馈，发布为 Pre-release，不替换现有稳定版，不代表所有真实权限组合已经验收通过。

## 新增与修复

- 新版三网按线路展示两小时窗口，支持小曲线、色块和历史点交互；每个来源可选最多三条线路，节点可独立覆盖，名称和绑定保持来源归属。默认不启用新版三网，旧配置维持原行为。
- 强化同源凭据边界：不把主站 JWT 或人机验证凭据发送到其他来源；多来源默认匿名，跨来源私有及独立 Turnstile 授权暂不支持。
- 遵守 CFSM 请求额度约束，不通过定时 REST 轮询推进页面或历史，断线不进行周期 REST 回退；配置按来源共享加载，详情默认十分钟，负载和延迟默认共用历史请求。
- 修复快捷筛选切换时卡片移位、过渡反馈消失的问题，保留真实节点身份和减少动态效果设置。
- 修复实时负载中的孤立采样不可见：稀疏样本显示为点，连续样本正常画线，真实缺口不连接、不插值、不补零。历史垫底统一秒和毫秒时间戳后再裁剪及去重。
- 新增“未登录时隐藏主题设置”，与“隐藏后台入口”独立。管理员保存到后端后，访客设置入口隐藏，直接访问 `#/settings` 返回首页；本地覆盖不能解除站点策略。默认关闭，完整已知设置数为 52 项。

## 使用说明

Agent WSS 是可选功能，HTTP 上报仍受支持。仅 HTTP 模式下，数据按 Agent 实际上报周期到达，实时图可能显示稀疏点，不保证秒级连续折线。本主题不会自行修改 Agent 上报参数。

新版三网需 CFSM 后台允许显示三网详情，并在主题设置中开启“启用新版三网”。首页三网展示的是列表获取时的两小时采样窗口快照，不是持续滚动的实时完整历史。

如需公开页面仅供查看，管理员登录后进入“主题设置 → 高级工具与隐私”，启用“未登录时隐藏主题设置”并保存到 CFSM 后端；是否隐藏管理端链接由另一个开关决定。隐藏入口后仍可直接打开站点的 `/admin#/admin` 登录，再返回首页刷新。入口限制只是前端界面策略，服务端保存仍独立鉴权。

## 验证范围与已知限制

- 本地已通过 lint、Bun 类型检查、Node 直接 Vue SFC 类型检查、70 文件/828 项测试、构建、dist 校验、安全模式扫描；依赖公告审计未命中当时数据库中的已知漏洞。正式候选产物由标签 Actions 重新检查、构建和打包，失败时不应使用半成品。
- 合成浏览器验证涵盖稀疏及连续实时图、访客入口隐藏和直接路由限制、管理员可见及默认配置兼容。用户反馈前一固定候选构建安装和设置入口控制正常，管理员完整保存及刷新读取也已有真实验收证据。
- 公开/私有与全局 Turnstile 开/关的完整真实组合、凭据续期、常规浏览器前后台恢复和真实回滚演练尚未全部闭环，不宣称这些项目均通过。
- 375px 下部分首页总览长数值可能省略；实际部署中的第三方统计脚本来源仍待核实，本地源码及产物未见该统计脚本。物理触屏和完整跨浏览器矩阵未完成。
- 后端完整配置保存没有服务端修订号锁，多管理员并发编辑可能发生最后写入覆盖。安全扫描不能证明绝对无漏洞。

## 安装与回滚

在 CFSM 管理端“主题商店 → 自定义主题 URL”填入本次成功发布后生成的固定产物标签：

[安装 v1.3.0-rc.1 候选主题](https://github.com/rcho19/CFSM-Theme-Glassmorphism/tree/theme-v1.3.0-rc.1)

该地址的内容由 `theme-v1.3.0-rc.1` 固定，包根目录仅包含 `index.html` 和 `assets/`。亦可从本次 GitHub Release 下载 `CFSM-Glassmorphism-v1.3.0-rc.1.zip`。不要用源码标签 `v1.3.0-rc.1` 作为主题安装地址。

升级前在私人位置备份旧主题固定地址和 `theme_options`，保留已登录管理端标签。回滚时重新安装原主题；仅在需要恢复主题配置时再恢复对应备份。本版新增键可被旧版忽略，但旧版不提供新设置入口限制。“使用后端配置”只清本地覆盖，不能撤销主题安装或恢复旧后端配置。候选发布不会推进稳定产物分支 `theme-dist`。

完整使用与回滚步骤见 [使用说明](../USAGE.md)，验收边界见 [发布前验收](../RELEASE_READINESS_2026-11-12.md)。
