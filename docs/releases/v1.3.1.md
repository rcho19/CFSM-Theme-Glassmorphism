# v1.3.1 正式版

本版集中修复首页节点卡片的三网交互与可读性，包含 v1.3.0 的既有功能，保留 MIT 许可和原作者署名。

## 修复与优化

- **三网入口直达延迟图表**：点击运营商名称、延迟或丢包数值后，详情页直接打开“延迟”标签；关闭分区标签时，等待图表加载完成后滚动到延迟区域。刷新深链接可恢复该分区，普通卡片点击仍打开概览，多来源归属保持正确。
- **延迟文字采用“同色微深”配色**：保持曲线原有五档状态色，在 sRGB 中为延迟数值混入黑色，浅色 28%、深色 5%，不降低饱和度；明暗及色觉友好模式均按当前信号色计算。缺失值不冒充零延迟，不可达保持红色语义。
- **文字与趋势分层**：运营商名称和“丢包”文字改用中性色，丢包数值使用独立文字色板，新增小型状态圆点，减少整行浅绿或黄绿造成的辨认困难。
- **收紧三网间距**：名称和数值列按内容宽度排列，各行共享列宽，数值与曲线保持 4px 间距，避免短名称后留下大块空白；长名称保留省略及完整提示。
- **构建工具链维护**：checkout 更新为使用 Node 24 的 v7.0.1，并锁定完整提交 SHA；为暂未发布官方修复版的 picomatch 增加本地缓解及严格受限的临时审计例外。

## 安装

在 CFSM 管理端“主题商店 → 自定义主题 URL”填写：

```text
https://github.com/rcho19/CFSM-Theme-Glassmorphism/tree/theme-v1.3.1
```

点击“应用自定义”，另开标签页刷新检查。也可下载本 Release 的 `CFSM-Glassmorphism-v1.3.1.zip`，包根仅包含 `index.html` 与 `assets/`。`theme-v1.3.1` 为固定产物标签，源码标签 `v1.3.1` 不能直接安装；正式质量门通过后稳定分支 `theme-dist` 会更新。

新版三网仍需后台“显示三网详情”和主题“启用新版三网”均开启。发布本版本不会自动替换现有站点主题，也不修改 Worker、数据库、Agent 或后端主题配置。

## 验证与边界

- 本地 lint、Bun 类型检查、独立 Node 的 Vue SFC 检查、71 文件 / 836 项测试、构建、dist 校验及源码/产物安全模式扫描通过；正式附件由标签 Actions 再次冻结安装、检查和构建。
- 本地 Chrome 合成数据检查覆盖 320 / 375 / 768 / 1440px、明暗及色觉友好模式。最终配色共 32 组组合，五档延迟数值颜色符合所选加深比例，间距保持 4px，无横向溢出。此前已验证分区跳转、刷新恢复及堆叠布局定位。
- 本次没有新增真实站点、物理触屏和完整跨浏览器验收，不把本地检查表述为这些场景均已通过。既有 v1.3.0 真实数据及权限验收仍按原记录归属。
- 首页两小时采样窗口与详情所选范围的延迟/丢包统计可以不同；统计口径、探测阈值、历史断点及请求策略保持原样，不补零、不插值、不增加定时 REST 轮询。
- 保留既有大分块构建提示；跨来源私有与独立 Turnstile 授权、配置并发覆盖等限制仍适用。

## 依赖缓解说明

picomatch 尚无可直接升级的官方修复发布，本版使用可审阅的 Bun 补丁作保守缓解。`bun run audit:dependencies` 先检查确切版本、已安装文件哈希及隔离子进程中的漏洞/兼容行为，全部通过后才精确排除 `GHSA-fc5q-39xc-vjpf`；其他公告、网络错误或校验失败仍阻断构建。原始 `bun audit` 仍会报告这一版本公告，不能宣称零漏洞。

临时例外于 **2026-12-02 00:00 UTC（北京时间 08:00）** 自动到期，届时必须复核并优先升级官方修复版本，不能直接顺延。到期只影响后续构建，不影响已经安装的主题运行。补丁会保守地将部分复杂单分支重复 glob 转为字面量，具体范围与移除路径见 [缓解记录](https://github.com/rcho19/CFSM-Theme-Glassmorphism/blob/v1.3.1/docs/DEPENDENCY_MITIGATION_2026-11-18.md)。

## 回滚

升级前在私人位置备份当前固定主题地址及 `theme_options`，保留已登录的管理页。需要回滚时，重新应用 [v1.3.0 固定版本](https://github.com/rcho19/CFSM-Theme-Glassmorphism/tree/theme-v1.3.0) 或原主题地址；仅在修改过后端配置时恢复相应备份。不要覆盖旧标签或把“清除本机覆盖”当作恢复后端配置。
