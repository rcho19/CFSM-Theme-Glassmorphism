# 安全加固与新版三网实施规格

状态：本地候选版已实施，真实平台发布验收待完成，2026-11-11。基线 d593caf；本规格是本轮范围与验收依据，优先于历史 CODEX_SPEC.md 中的仓库地址、分轮推送及已过时数据约定。结果见 IMPLEMENTATION_RESULTS.md。

## 目标与边界

必须在当前目录开发，保留 MIT 许可和上游署名。不向 allury 或其他外部仓库推送；由用户后续选择公开仓库。不得修改 Worker、数据库、Agent，不得操作真实站点或支付、删除数据。不承诺绝对无漏洞，必须提供安全检查证据、剩余风险和可复验步骤。

## 架构所有权

HTTP/WS 层负责来源与凭据；adapter 负责 unknown 数据校验；store 负责按来源配置、共享刷新与生命周期；domain 负责线路选择与统计；Vue 组件只负责展示及交互。主题唯一写端点仍为 POST /api/theme_options。安全策略不依赖 UI 隐藏实现。

必须阻止主站 JWT、Turnstile 凭据出现在其他 origin 的 HTTP 头或 WS URL；远端默认匿名，不提供跨来源管理员认证。来源错误不得清除其他来源凭据。origin 比较包括协议、主机、端口。开发 mock 不得接触真实凭据。

## 三网数据及配置

保持 CFSM 两小时窗口和真实时间桶，不伪造原始探测时刻或一小时加权统计。false/null/0 必须区分，全失败仅在窗口 loss=100 时展示不可达。关闭 show_three_net_details 时不显示窗口小图。新三网功能默认关闭，旧配置保持原表现；启用后默认 ct/cu/cm，允许从八目标选最多三条。全局选择按 API origin，节点覆盖键包含 origin 与服务器 ID，未知/失效绑定可删除。

根据用户补充的 CFSM theme-ai-prompt.md，禁止定时 REST 轮询，包括旧版断线回退。首页窗口为首次列表响应的快照；可见性恢复可补一次列表并重连，旧快照必须明确标记。配置每来源在页面生命周期只加载一次，详情负载和 Ping 共用一次历史请求，默认 0.167 小时。不得逐卡请求历史。此前审查中的五分钟窗口轮询方案作废。

必须包括小曲线/色块模式、鼠标/触屏/键盘历史点选择、正确断点、稳定比例和防过冲。复用上游 Sparkline 实现；完整图表入口复用现有详情页。配置沿用默认/后端/浏览器三层，并保留未知后端字段。

## 隐私与供应链

不增加遥测、广告、指纹、IP 地理查询、远程执行或运行时图标 CDN。列明全部外部请求及开关。不得记录 Token/Cookie、真实服务器地址或本机路径到公开文档。依赖最小升级、冻结锁文件，审计已知漏洞；开发工具风险与发布产物风险分别说明。公开前扫描源码、差异和 dist；不上传 node_modules、.env、生产配置或临时审查日志。

## 阶段与质量门

1. 安全：来源隔离及 401/403 回归、依赖治理。
2. 数据：三网开关、按来源名称、窗口刷新和过期状态。
3. UI：配置 schema、线路选择、曲线与色块、无障碍。
4. 交付：中文安装/开发/隐私/回滚说明、上游同步记录、结果报告。

每阶段必须做对应行为测试；最终必须通过 lint、Node 下 Vue SFC 类型检查、全部测试、构建、dist 校验和依赖审计。浏览器必须验证 320/375/768/1440 宽度、明暗、卡片密度及交互；真实站点和无法验证项目必须明确记录，不能以静态检查冒充。

回滚以旧稳定主题引用和旧 theme_options 为依据，新键必须可被旧版忽略。本轮不发布、不推送、不打稳定标签。
