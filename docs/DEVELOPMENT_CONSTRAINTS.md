# 本轮开发约束

- 当前用户授权高于历史开发规范；不执行历史规范中的自动提交、推送和发布要求。
- 必须使用 Bun 锁文件及既有 Vue/TypeScript/Vite/ECharts/reka-ui 体系，不无关重构。
- 不修改上游参考检出，不引入任何真实 API_SECRET、JWT、Cookie、服务器清单。
- 测试只使用 example/invalid 域名和合成数据，禁止向生产站点写入。
- 新配置、组件、刷新器必须有明确生命周期及来源归属。
- 安全校验与统计行为测试必须验证结果，不能只匹配源码字符串。
- 任何检查失败必须解决或如实列为交付阻塞；不得把未执行的浏览器或生产检查写成通过。
- 公开仓库不得附带临时终端日志与机器路径；历史审查原文属于本地档案，公开前清理或排除。
